# Encargos

Cada archivo es un encargo numerado, `NN-<slug>.md`, escrito por el
orquestador (`/orquestador`) y ejecutado por una sesión de trabajo con
`/encargo NN`. Lleva sólo lo específico de la tarea; lo fijo (qué leer,
reglas de trabajo, cómo se cierra) está en `.claude/skills/encargo/SKILL.md`.
La plantilla está en `.claude/skills/orquestador/references/plantilla-encargo.md`.
